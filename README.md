# TriVault — static launch

The current release keeps the corporate site, Odor Removal, Estimates and the roof intake visible. No online form, upload or appointment is transmitted in this phase. Clients contact TriVault by phone or email.

Public files are available at the repository root for an existing root-based GitHub Pages configuration and under frontend/ for a frontend-only deployment. Keep these synchronized when editing. Do not deploy backend/ as an application until separately configured and tested.

See docs/STATIC-INSTALL.md. The earlier exposed Azure credential must be revoked; removing documentation does not revoke it or erase Git history. Never store credentials in this repository.
